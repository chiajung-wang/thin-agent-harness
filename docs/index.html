The Founder orchestrates directly to five IC agents — Builder, Designer, Researcher, Marketer, Critic — over a single shared blackboard. ICs fan out in parallel when their outputs are independent, then the Founder synthesizes. No sub-orchestrators. No message bus. The entire runtime state is one markdown file.

Mental Model

  • Write asymmetry — only the Founder writes Decisions and Spec; only the Marketer writes Positioning; all other ICs are read-only.
  • Severity ladder — Critic tags each finding blocker, major, minor, or nit, and never writes fixes, preserving the Founder's remediation authority.
  • Verification ladder — Builder climbs typecheck, lint, targeted test, smoke run in order, stopping at the first real signal, not running the full suite.
  • Stage-report cadence — at every stage boundary, one render pass emits synced HTML, JSON, and chat Markdown from a fixed four-layer template.
  • Growth triggers — a bureaucracy layer is added only when observed pain demands it: saturated context window, recurring conflict, or irreversible actions in scope.

Tradeoffs

DAG planner

Founder picks the next step inline and replans after each result. A static graph front-loads decisions the Founder does not yet have enough information to make.

Sub-orchestrator middle managers

ICs report directly to the Founder. No middle layer means no telephone game, no split intent ownership, no extra context cost at each routing hop.

Per-IC blackboard writes

Only the Marketer appends to the blackboard; all other ICs return through Founder synthesis. One writer per section prevents silent clobber and keeps memory auditable.
