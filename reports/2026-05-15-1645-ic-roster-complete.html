TL;DR

Full IC roster (builder, researcher, designer, marketer, critic) and founder-side skill table landed in commit 946c8c7; topology is now structurally complete and ready for end-to-end dry-run.

Mental model

  • IC template as a contract: every IC shares the same shape — frontmatter, responsibilities, JSON in/out, operating rules, skill table, anti-patterns, escalation, blackboard rules — so the founder can route without reading each file in full.
  • Skill tables as procedural overrides: each agent maps domain triggers to addy-agent-skills, turning improvised reasoning into named playbooks that can be audited via skills_invoked.
  • Blackboard write asymmetry: only founder writes Decisions and Spec; only Marketer writes Positioning; all other ICs are read-only and return through founder synthesis.
  • Severity ladder as the ship gate: Critic returns verdict + severity-tagged findings (blocker/major/minor/nit) instead of fixing — preserves founder's authority over remediation.
  • Verification ladder as cheapest-signal-first: Builder climbs typecheck → lint → targeted test → smoke run and stops at first real signal, avoiding full-suite cost on small changes.
