TL;DR

Topology chosen (flat startup), Founder agent and stage-report skill written; five IC agents still pending and blackboard now exists as the shared memory substrate.

Mental model

  • Company-as-harness: a startup org chart maps onto an agentic system where ICs are specialist agents and the orchestrator is the founder.
  • Blackboard-first memory: a single shared markdown file holds Intent, Spec, Decisions, and Open questions — every agent reads from and appends to it.
  • Skill vs agent split: rigid, format-stable procedures (like stage reporting) live as project skills; autonomous task workers live as agents.
  • Human-agent dual rendering: each stage emits HTML (for humans, with a diagram) and JSON (for agents, machine-readable) from a single shared state model, so both sides share one mental model.
  • Muscle memory by repetition: a fixed four-layer report shape (TL;DR / Mental model / State delta / Open questions) trains the human reader to scan and absorb project state quickly.
